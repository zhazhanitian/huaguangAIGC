## 四、修复方案

### 方案A（推荐）：退款后清零 deductPoints，重试时跳过已退款任务

**修改 `draw.processor.ts`：**

```typescript
@Process({ name: 'process', concurrency: 5 })
async handleProcess(job: Job<{ taskId: string }>) {
  const { taskId } = job.data;
  const task = await this.drawRepository.findOne({ where: { id: taskId } });
  if (!task) return;

  // 如果任务已是终态（failed/completed），跳过处理（可能是重试时已被处理）
  if (task.status === DrawTaskStatus.FAILED || task.status === DrawTaskStatus.COMPLETED) {
    this.logger.warn(`[skip] 任务 ${taskId} 已是终态 ${task.status}，跳过重试`);
    return;
  }

  await this.drawService.processDrawTask(task);
}
```

**修改 `draw.service.ts` 退款逻辑：**

```typescript
// 失败时退还积分（只退一次）
const refundPoints = Number(task.deductPoints ?? 0);
if (refundPoints > 0) {
  task.deductPoints = 0;  // 清零，防止重试时二次退款
  await this.drawRepository.save(task);
  try {
    await this.userService.addBalance(task.userId, refundPoints);
  } catch (refundErr) {
    this.logger.error(`退还积分失败: ${task.userId}`, refundErr);
  }
}
// 不再 throw err，改为直接 return，Bull 不会重试
```

### 方案B（快速止血）：将 Bull 重试次数改为 1

```typescript
await this.drawQueue.add(
  'process',
  { taskId: saved.id },
  { attempts: 1 },  // 不重试，失败就失败
);
```

> 注意：方案B治标不治本，如果服务重启导致任务重新入队，仍可能有二次退款问题。
